# Работа с проектом ОТАЛ

- В начале каждой задачи читать `TODO.md` в корне проекта.
- Поддерживать `TODO.md` в актуальном состоянии: добавлять задачи по просьбе пользователя и отмечать выполненными только после фактического завершения и проверки.
- В каждом итоговом ответе по этому проекту кратко напоминать пользователю о незавершённых пунктах из `TODO.md`. Если все пункты завершены, сообщать об этом без повторения закрытых задач.
- Наличие пункта в TODO само по себе не означает поручение немедленно его выполнять: придерживаться текущего запроса пользователя.
