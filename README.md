# ОТАЛ — інженерія енергії

Статичний україномовний сайт-візитка. Без встановлення залежностей і збірки.

## Запуск

```sh
npm start
```

Локальний сайт: http://localhost:4173. Інший порт: `PORT=8080 npm start`. Потрібен Node.js 18+. Зупинка — Ctrl+C.

## Структура та оформлення

Композиція адаптована за https://eg-ltd.com.ua/: три фотопанелі на головному екрані, компанія, переваги, обладнання, послуги, галерея, запрошення до контакту й контакти. Збережені кольори попередньої версії ОТАЛ (`#17201d`, `#f4f5ee`, `#d5f66b`) і Manrope. Відомості про клієнтів, виробництво та гарантії іншої компанії не перенесені.

На великих екранах при наведенні або фокусі на панелі збільшується фото, змінюється затемнення, розширюється акцентна лінія та з’являються опис і кнопка. На телефонах панелі йдуть вертикально; опис і кнопки видимі постійно. Посилання відкривають відповідний розділ послуг. Галерея підтримує кнопки, індикатори, клавіші стрілок і свайп.

Анімації появи секцій, лічильника та акордеона враховують `prefers-reduced-motion`. Кнопка паузи зберігає вибір локально. Обробка прокручування об’єднана в requestAnimationFrame; постійних таймерів немає.

## Зв’язок

Телефонні та поштові посилання працюють напряму. Форма заявки надсилає ім’я, телефон і опис завдання через **FormSubmit** на `fotoromario@gmail.com` без відкриття поштової програми. Публічна контактна адреса компанії `ser_energo@ukr.net` залишена окремо від одержувача заявок.

- Endpoint: `https://formsubmit.co/ajax/fotoromario@gmail.com`.
- Нативна POST-відправка без JavaScript: `https://formsubmit.co/fotoromario@gmail.com`.
- Документація: https://formsubmit.co/ajax-documentation та https://formsubmit.co/help.
- Перед запуском: надіслати тест із **публічного домену сайту**, відкрити лист активації FormSubmit у Gmail (перевірити також спам) і підтвердити адресу. Потім повторно надіслати тест та перевірити доставку. Активація і фактична доставка ще потребують підтвердження власника пошти.
- Сервіс отримує дані звернення. Пароль Gmail і ключі в коді не потрібні.
- Під час запиту кнопка заблокована; успіх показується лише після успішного HTTP-відгуку та `success: true` або `"true"`. Це підтвердження прийняття сервісом, а не гарантія доставки в Gmail.
- При помилці дані залишаються у формі. Таймаут — 20 секунд без автоматичних повторів, щоб уникнути дублювання. Є приховане поле `_honey` для базового захисту від ботів; стандартну CAPTCHA FormSubmit не вимкнено.
- Для роботи потрібен HTTP(S), а не відкриття HTML як `file://`.

## Перевірки

```sh
npm run check
```

Перевіряє синтаксис app.js і server.mjs.

Браузерна перевірка 15.10.2026 (Chrome, ARM): ширини 320, 390, 768, 1024 та 1440 px без горизонтального переповнення; перевірені hover панелей, перехід до послуги, кнопки галереї, мобільне меню, відкриття діалогу, Escape, reduced motion та валідація телефону. Помилок JavaScript не виявлено. Перевірені знімки головного екрана, мобільної версії та всієї сторінки. Доставку листа через FormSubmit ще не підтверджено.
