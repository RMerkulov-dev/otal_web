# ОТАЛ — інженерія енергії

Статичний україномовний сайт-візитка. Без встановлення залежностей і збірки.

## Запуск

```sh
npm start
```

Локальний сайт: http://localhost:4173. Інший порт: `PORT=8080 npm start`. Потрібен Node.js 18+. Зупинка — Ctrl+C.

## Структура та оформлення

Композиція адаптована за https://eg-ltd.com.ua/: три фотопанелі на головному екрані, компанія, переваги, обладнання, послуги, галерея, запрошення до контакту й контакти. Збережені кольори попередньої версії ОТАЛ (`#17201d`, `#f4f5ee`, `#d5f66b`) і Manrope. Відомості про клієнтів, виробництво та гарантії іншої компанії не перенесені.

На великих екранах при наведенні або фокусі на панелі збільшується фото, змінюється затемнення, розширюється акцентна лінія та з’являються опис і кнопка. На телефонах панелі йдуть вертикально; опис і кнопки видимі постійно. Посилання відкривають відповідний розділ послуг. Галерея підтримує кнопки, індикатори, клавіші стрілок і свайп.

Анімації появи секцій, лічильника та акордеона враховують `prefers-reduced-motion`. Кнопка паузи зберігає вибір локально. Обробка прокручування об’єднана в requestAnimationFrame; постійних таймерів немає.

## Зв’язок

Телефонні та поштові посилання працюють напряму. Діалог зв’язку має форму, що **готує лист через mailto**. Користувач надсилає лист зі своєї поштової програми. Сайт не відправляє заявки на сервер і не повідомляє про нібито успішну доставку. Для автоматичної доставки потрібен окремий поштовий сервіс або серверний обробник.

## Перевірки

```sh
npm run check
```

Перевіряє синтаксис app.js і server.mjs.

Браузерна перевірка 15.10.2026 (Chrome, ARM): ширини 320, 390, 768, 1024 та 1440 px без горизонтального переповнення; перевірені hover панелей, перехід до послуги, кнопки галереї, мобільне меню, відкриття діалогу, Escape, reduced motion та валідація телефону. Помилок JavaScript не виявлено. Перевірені знімки головного екрана, мобільної версії та всієї сторінки. Доставку листа не перевіряли: її виконує поштова програма користувача.
