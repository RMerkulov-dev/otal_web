# ОТАЛ — сайт-візитка

Односторінковий сайт ТОВ «ОТАЛ» (Теплодар, Одеська область). Його задача — бути видимим у пошуку
за запитами на електромонтажні роботи й заводити відвідувача в каталог компанії на Prom.ua:
<https://ser.od.ua/ua/>. Сам каталог лишається там, тут — вся решта: хто це, що роблять, за скільки
і як звʼязатися.

## Стек

| Що | Чим | Чому так |
| --- | --- | --- |
| Збірка | Astro 7 | На виході статичний семантичний HTML. Нуль JavaScript за замовчуванням. |
| Компоненти | React 19 «острівцями» | React вантажиться лише там, де є інтерактив; решта — звичайна розмітка. |
| Анімації | CSS + Motion 14 (`motion/react`) | Сцени й рух фото першого екрана — CSS і короткий скрипт; Motion — лише мобільне меню. |
| Шрифти | Свої woff2 | Жодних запитів до fonts.googleapis.com і fonts.gstatic.com. |

Реакт тут потрібен лише як мова компонентів. Усе, що видно пошуковику й людині без JavaScript, —
це HTML, згенерований на збірці.

## Запуск

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # статика в dist/
npm run preview  # перевірити зібране
npm run check    # типи та діагностика Astro
```

Потрібен Node.js 20 або новіший.

## Перед публікацією

Відкрийте `astro.config.mjs` і замініть `SITE_URL` на реальний домен сайту-візитки. Від нього
залежать `canonical`, `og:url`, `sitemap-index.xml` і `robots.txt`. Це **не** `ser.od.ua` — там
каталог, куди візитка веде.

Далі `npm run build` і віддайте вміст `dist/` будь-яким статичним хостингом. Увімкніть на сервері
стиснення (gzip або brotli) і довге кешування для `/_astro/`.

## Де що лежить

```
src/
  data/company.ts      контакти, адреса, години, навігація — одне джерело правди
  data/services.ts     шість напрямів робіт, позиції з цінами, посилання на Prom.ua, фото
  layouts/Base.astro   head, SEO-теги, JSON-LD (schema.org Electrician)
  components/          секції сторінки; .astro — статика, .tsx — React-острівці
  styles/global.css    дизайн-токени та оформлення
legacy/                попередні версії сайту (vanilla HTML/CSS/JS), не збираються;
                       legacy/vercel-2026-10-15/ — версія, що була на otalweb.vercel.app
```

Щоб змінити назву послуги чи посилання — редагуйте `src/data/services.ts`. Розмітка,
структуровані дані та список у підвалі оновляться самі. Тексти шести перших екранів —
у `src/components/Hero.astro`, фото до них — у `src/assets/hero/`.

## Контент

Послуги й посилання взяті з каталогу ТОВ «ОТАЛ» на Prom.ua. Цін на сайті немає свідомо: їх
довелося б постійно оновлювати, вартість компанія рахує під завдання. Дві цифри в «Про компанію»
(роки на ринку, кількість об’єктів) — заглушки `XX`, позначені `todo: true` в `About.astro`.

## Дизайн

Глибокий синій емалі шаф КРП `#0f2133`, білі й сріблясто-сірі поверхні, жовтий знака
«Обережно! Висока напруга» `#f5b800` — лише дрібними акцентами, не на кнопках. Заголовки й
текст — Onest (одне семейство, варіативний шрифт).

Перший екран — шість повноекранних сцен, по одній на розділ каталогу. Поки секція прокручується,
сцени змінюють одна одну (липкий в’юпорт), далі сторінка гортається як звичайно. Поверх фото —
модульна сітка з шести колонок, до якої вирівняні тексти й цифри.

## Анімації та швидкість

| Де | Що робить |
| --- | --- |
| Сцени першого екрана | Плавна зміна фото (1,4 с) і тексту; запас на межі сцен, щоб вони не блимали. |
| Автопоказ | Хвилину без кліку, прокручування чи клавіш — сцени гортаються самі кожні 7 с по колу, сторінка не прокручується. Будь-яка дія зупиняє показ. Не грає у прихованій вкладці й коли перший екран прокручено. Час — `IDLE_MS` і `STEP_MS` у `Hero.astro`. |
| Енергія на першому екрані | По лініях сітки біжать імпульси струму; при зміні сцени лінією під шапкою пробігає імпульс. Фото нерухомі. Лише `transform` і `opacity`; коли перший екран прокручено — пауза. |
| Мобільне меню | Розкривна панель, бургер перетворюється на хрестик. |

Фото першого екрана Astro віддає в AVIF/WebP під ширину екрана (640–1672 px, ~40–215 КБ).
Одразу вантажаться лише перша сцена й наступна; решта лежить у `<noscript>` і з’являється, коли до
неї лишається одна сцена. `prefers-reduced-motion: reduce` вимикає імпульси й переходи. Без
JavaScript сцени стоять одна під одною з усіма фото.

## Шрифт

Onest підключено пакетом `@fontsource-variable/onest`: файли woff2 збираються разом із сайтом у
`/_astro/`, жодних запитів до Google Fonts. Один варіативний файл покриває всі накреслення;
браузер вантажить лише потрібні підмножини (кирилиця, латиниця). Якщо міняєте шрифт, оновіть
імпорт і `rel="preload"` у `src/layouts/Base.astro` та змінні `--font-*` у `global.css`.
