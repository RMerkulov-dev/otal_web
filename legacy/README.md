# ОТАЛ — інженерія енергії

Статичний україномовний сайт. Збірка та встановлення пакетів не потрібні.

## Запуск

Відкрийте `index.html` у браузері або виконайте в цій папці:

```sh
npm start
```

Сайт буде доступний на http://localhost:4173. Для іншого порту: `PORT=8080 npm start`.
Потрібен Node.js 18 або новіший. Зупинка сервера — Ctrl+C.

## Анімації

`app.js` керує появою секцій, паралаксом, рухом шарів за курсором, лічильниками, плавним розкриттям послуг, прогресом читання, активною навігацією та мобільним меню. `style.css` містить оформлення, картки з накладанням під час прокручування, світлові ефекти та адаптацію.

Кнопка внизу екрана вимикає анімації й запам’ятовує вибір, коли доступне локальне сховище. Системне налаштування `prefers-reduced-motion` має пріоритет. На низьких екранах картки показуються звичайним списком, щоб не перекривати текст.

## Перевірка

```sh
npm run check
```

Синтаксис JavaScript та локальні посилання перевірені. HTTP-сервер і Chromium не вдалося запустити в середовищі редагування через обмеження дозволів; візуальна перевірка на комп’ютері й телефоні ще потрібна.

## Послуги в колі й оптимізація

Бігучу стрічку видалено. Шість послуг змінюються в центрі кола кожні 4,5 секунди. Кнопки під колом перемикають послуги вручну; натискання назви відкриває відповідний розділ. Автозміна зупиняється при наведенні, фокусі клавіатури, виході головної секції за межі екрана, приховуванні вкладки та вимкненні руху. Ручне перемикання доступне і без автозміни.

Прокручування обробляється одним запланованим кадром: спочатку всі вимірювання, потім зміни стилів. Незмінні значення повторно не записуються. Вимірювання паралаксу й карток пропускаються поза екраном; на сенсорних і малих екранах вимкнено паралакс фото, глибину карток і додаткове сканування. CSS-анімації невидимих секцій та прихованої вкладки призупиняються. Постійні підсвічування використовують opacity/transform замість зміни тіней і позиції градієнта; розмиття фону поверх рухомих шарів прибране. Шрифт підключено напряму з HTML замість CSS @import.

Синтаксис та поведінку планувальника перевірено Node.js-перевіркою з імітацією DOM: об’єднання подій в один кадр, порядок читання/запису, зупинка поза екраном і в прихованій вкладці, ручне та автоматичне перемикання, пауза при наведенні/фокусі та reduced motion. Це не браузерний профіль: фактичні FPS і навантаження CPU/GPU в цьому середовищі не виміряно.

Реакцію головного екрана на рух курсора прибрано: немає обробника pointermove та зміщення фото, заголовка або кола слідом за мишею. Наведення на коло лише призупиняє автозміну послуг для зручного читання.
